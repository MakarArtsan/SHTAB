# data

Справочники, которые читает приложение. Это данные, а не код: правки сюда
не требуют выкладки нового образа.

- `categories.json` — категории инцидентов, приоритеты и целевое время реакции (ТЗ 6.2 и приложение А)

Появятся дальше по плану: узлы пилотного региона, шаблоны жалоб,
контрольные соотношения протокола, статьи базы знаний.
